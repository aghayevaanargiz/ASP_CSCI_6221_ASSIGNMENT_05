## Overview

This repository contains my implementations and technical reports for **Assignment 5: Functional Programming**, assigned as part of the Advanced Software Paradigms course.

The assignment focuses on solving [e-Olymp Problem 1964: What is left?](https://eolymp.com/en/problems/1964) using two different programming paradigms: imperative and functional programming.

The same problem will be approached using two programming languages to explore the differences in their programming styles, data processing techniques, and performance.
